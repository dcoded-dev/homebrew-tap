# DCODED Homebrew tap

Mac apps from [DCODED](https://dcoded.dev), installable with [Homebrew](https://brew.sh).

## Songtide

A native YouTube Music app for Mac with an equalizer, visualizer and synced lyrics. Free. [songtide.dcoded.dev](https://songtide.dcoded.dev)

```bash
brew install --cask dcoded-dev/tap/songtide
```

Songtide updates itself once installed. It is signed and notarized by Apple.

Songtide is an independent app and is not affiliated with, endorsed by or sponsored by Google or YouTube.
